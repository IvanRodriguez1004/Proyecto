## Descripción

Sistema de gestión para talleres mecánicos y propietarios de motocicletas que permite administrar clientes, vehículos, mantenimientos, inventario de repuestos y generar alertas preventivas para servicios futuros.

## Objetivos

- Gestionar información de clientes y motocicletas.
- Registrar mantenimientos realizados.
- Controlar inventario de repuestos.
- Generar alertas para cambios de aceite y revisiones preventivas.
- Preparar una base tecnológica para futuros modelos predictivos basados en inteligencia artificial.
